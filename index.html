Web Crypto API unavailable

This simulator performs real cryptography using window.crypto.subtle. Your browser did not expose it for this page, so the vault cannot run. This normally happens only in older browsers or in an insecure context.

Serve the folder over localhost (a secure context) and reload:

cd "<this folder>"
python -m http.server 8000
# then open   http://localhost:8000/index.html

Helper scripts serve.bat (Windows) and serve.sh (macOS/Linux) are included next to this file. Chrome and Firefox both treat file:// as a secure context, so double-clicking index.html normally works without a server.
